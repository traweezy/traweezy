# Tool icon sources

Static copies prevent upstream outages or renames from breaking the profile.
The manifest records each source URL and SHA256 checksum.

* [Skill Icons](https://github.com/tandpfun/skill-icons): [skill-icons-LICENSE.txt](skill-icons-LICENSE.txt).
* [Skills Icons](https://github.com/syvixor/skills-icons): [skills-icons-LICENSE.txt](skills-icons-LICENSE.txt).
* [Simple Icons](https://github.com/simple-icons/simple-icons): [simple-icons-LICENSE.txt](simple-icons-LICENSE.txt).

Meilisearch and Testing Library use Simple Icons paths in matching rounded tiles.
Railway uses the Skills Icons asset because the old endpoint returned an empty SVG.
Brand names and marks belong to their respective owners.
